# Sample data (FICTIONAL)

Every person, university, email and paper in this folder is invented, so you can practise safely. The domains end in `.example`, a reserved name that cannot receive email, and the tool refuses to send to sample records.

- `sample_professors.csv`: seven practice records that show each tool feature: a strong fit, an IELTS 7.0 program, a machine-learning fit, an unverified record, a duplicate, a department that discourages contact, and an opt-out.
- `sample_suppression_list.csv`: a practice suppression list.

To practise: `python -m src.cli init --sample`, then `python -m src.run_pipeline`.
